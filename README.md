# FRC Shop Tool Tracker

A QR code-based inventory management system designed for FIRST Robotics Competition (FRC) workshops. The application allows users to scan QR codes attached to tools and instantly retrieve inventory information from a Firebase Firestore database.

## Features

- QR code tool identification
- Firebase Firestore cloud database
- Fast lookup of inventory information
- Built with JavaScript, HTML, CSS, and Vite

## Technologies

- JavaScript (ES6)
- HTML5 & CSS3
- Firebase Firestore
- Vite
- html5-qrcode
